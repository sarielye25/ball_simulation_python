第二阶段训练 · 学习讲义

实验 2 与实验 3
损失函数、物理容差与运动表示

先把学习目标说清楚，再测试模型是否需要更好的物理输入。本文把项目当前做法、建议的对照实验，以及容易误判的地方分开说明。

阅读路线：实验 2 回答“模型正在优化的数值，是否符合我想要的物理精度？”实验 3 回答“即使训练目标合理，输入是否仍然没有清楚表达分段的运动规律？”两项可以在同一阶段准备，但比较时仍应固定其他条件、一次只改一个因素。

0. 先认识项目中的两个输出

对第 i 条样本，模型输入是初速度 v0、外力 F、施力时长 t1、观察时间 t；目标是位移 di（米）和最终速度 vi（米/秒）。模型预测分别记为 d̂i、v̂i。每批有 B 条样本。

现有网络是 4 → 32 → 32 → 32 → 2。训练时，两个目标先按训练集统计量标准化，再用 PyTorch 的 MSELoss(reduction="mean") 计算损失。项目在评估时又把预测转回物理单位，计算物理误差和容差通过率。

1. 实验 2：MSE 到底在算什么？

1.1 最基本的 MSE

均方误差（Mean Squared Error）是“每个误差先平方，再求平均”。如果只预测位移，物理单位下的公式是：

MSEd = (1/B) × Σi=1…B (d̂i − di)² 单位是 m²；平方让较大的误差受到更重惩罚。

速度的 MSE 同理，但单位是 (m/s)²。直接把这两个数相加会混合不同单位，也隐含了未经说明的权重。因此当前项目先把两个目标分别标准化。

1.2 训练集标准化与当前损失的完整公式

令 μd, σd 分别为训练集位移的均值和标准差；速度对应 μv, σv。目标和预测使用同一套训练集参数：

zd,i = (di − μd)/σd，  ẑd,i = (d̂i − μd)/σd
zv,i = (vi − μv)/σv，  ẑv,i = (v̂i − μv)/σv
Lstd = (1/2B) × Σi=1…B [ (ẑd,i − zd,i)² + (ẑv,i − zv,i)² ]
= (1/2B) × Σi=1…B [ ((d̂i − di)/σd)² + ((v̂i − vi)/σv)² ]分母为 2B，是因为一次平均覆盖 B 条样本 × 2 个输出。均值 μ 在“预测 − 真实”时抵消。

这意味着当前损失在物理单位下的相对权重是 1/σd² 与 1/σv²。它让“相对于训练集典型波动”的误差可比，但不保证符合你的精度要求。

2. 什么是这里的“物理容差”？

容差 τ 是你允许预测与真实答案相差多少的物理单位门槛。它不是训练集标准差，也不是 MSE；标准差来自数据分布，容差来自任务要求。

项目现有档位位移容差 τd速度容差 τv含义
coarse0.1 m0.1 m/s较宽松
intermediate0.01 m0.01 m/s当前停止判据选用的档位
fine0.001 m0.001 m/s更严格

当前评估代码认为一条样本通过某档位，当且仅当两个误差同时严格小于各自的容差：

passi = 1{ |d̂i − di| < τd 且 |v̂i − vi| < τv }
通过率 = (1/N) × Σi=1…N passi例如位移误差 0.008 m、速度误差 0.012 m：在 intermediate 档位不通过，因为速度超出了 0.01 m/s。

关键区别：这个通过率是评估指标，0 或 1 的跳变不适合直接作为常规梯度训练损失。实验 2 是用容差构造一个平滑、可求导的损失，引导模型提高容差通过率。

2.1 一个容差归一化的 MSE

定义两种无量纲误差：rd,i = (d̂i − di)/τd，rv,i = (v̂i − vi)/τv。绝对值为 1 表示恰好到达容差边界。

Ltol = (1/2B) × Σi=1…B [ ((d̂i − di)/τd)² + ((v̂i − vi)/τv)² ]这里的 1/2B 与当前 MSE 的平均方式一致；若用 1/B，优化方向相同，但数值与梯度会整体放大两倍。

以 intermediate 容差为例，位移误差 0.02 m 对应 rd=2、平方贡献 4；速度误差 0.005 m/s 对应 rv=0.5、平方贡献 0.25。损失会更关注前者，因为它超过了目标容差。

2.2 为什么两种 MSE 可能给出不同方向？

假设仅为演示，训练集的 σd=2 m、σv=0.5 m/s；某样本的位移误差为 0.02 m、速度误差为 0.01 m/s；两项容差都是 0.01（各自有单位）。

方法位移平方项速度平方项这一行的平均损失
当前标准化 MSE(0.02/2)² = 0.0001(0.01/0.5)² = 0.00040.00025
容差归一化 MSE(0.02/0.01)² = 4(0.01/0.01)² = 12.5

这些标准差是假设值，不代表项目真实数据。两种损失的绝对数值不能直接比较；要比较它们训练出的模型在同一验证集上的表现。

在这个例子里，标准化 MSE 更重视速度项；容差 MSE 更重视位移项。这正是实验 2 要检验的“输出权重是否限制实用精度”。

3. 容差损失如何在现有标准化模型上计算？

网络输出仍然是标准化预测，不需要为了换损失而重写输出层。因为 d̂ − d = σd(ẑd − zd)，速度亦然，所以：

Ltol = (1/2B) × Σi=1…B [ wd(ẑd,i − zd,i)² + wv(ẑv,i − zv,i)² ]
wd = (σd/τd)²，  wv = (σv/τv)²

这与先反标准化再计算完全等价（浮点舍入误差除外）。若权重很大，原封不动沿用旧学习率可能使梯度尺度发生巨大变化。为了主要考察两个输出的相对权重，可以把两个权重同时除以它们的平均值：

w̄ = (wd + wv)/2；  w̃d = wd/w̄，  w̃v = wv/w̄
Lweighted = (1/2B) × Σ [ w̃dΔzd,i² + w̃vΔzv,i² ]共同缩放不改变两项的相对偏重，但会改变损失数值和梯度量级。因此要明确记录采用的是原始容差损失还是归一化权重版本。
一个重要边界：平方损失并不直接等于“最大化通过率”。两条模型可能有相近的容差 MSE，却因错误分布不同而有不同的通过率。因此必须同时报告总体通过率、位移与速度的分项误差，以及高分位误差。

3.1 可解释的对照设计

  1. 先完成实验 1，选定学习率策略；对每个种子保留同一个起始检查点。
  2. 从该检查点复制两份。A 组继续用标准化 MSE；B 组用容差加权 MSE。两组都额外训练同样数量的更新。
  3. 两组使用相同训练集、批次顺序、微调学习率策略和模型结构。优化器状态要统一处理：要么两组都重置，要么两组都按同样规则恢复，并在记录中写清楚。
  4. 在原验证集上用同一套评价代码比较。至少看总体标准化 MSE、位移/速度 MAE、95 分位误差、intermediate 通过率及各运动组通过率。
  5. 跨三个种子报告均值和逐种子结果。只凭一次运行或只看训练损失，无法判断结论是否稳定。

若 B 组的目标通过率提升，但其他关键指标明显恶化，应说明权衡，不能简单宣布它“更准确”。若两组表现几乎相同，可能说明输出权重不是当前主要瓶颈。

4. 实验 3：什么叫“改变表示”？

现有网络只看到四个原始输入，需要自己从中学会：施力阶段与撤力阶段的区别、静摩擦阈值、停止时刻，以及不同运动状态之间的切换。对于 ReLU 网络，这些关系可能很难在数据有限时学准，尤其在分界附近。

表示的意思：不是改变正确答案，而是改变模型看到输入的方式，或改变预测结构，使重要的物理关系更容易表达。

5. 实验 3A：先试简单的物理特征

保留原始四输入，再追加只由输入与已知物理常数计算的特征。下表列的是候选项，不建议第一次就全部加入。

候选特征公式想帮助模型识别什么注意
撤力后时长Δt = t − t1撤力后摩擦还有多久使物体减速与原输入有冗余，但把关键组合直接给出
相对静摩擦阈值q = |F| − μsmg从静止开始时能否突破静摩擦项目物理参数对应阈值约 3.924 N；符号有意义
施力冲量J = Ft1外力的大小与持续时间共同影响速度只是物理启发，不是完整的最终速度公式

第一轮可以只加 Δt；第二轮再单独测试 q。若想比较“一个特征组合”，应在单项效果看清后再组合。每次改变输入维数时，首层权重矩阵也会变，参数量略有变化；要记录这一点，必要时用参数量相近的对照网络复核。

新增特征的均值与标准差必须只在训练集拟合；验证和部署使用相同变换。绝不能用真实最终速度、真实位移、或依据答案计算出的运动组，来生成预测时的特征。

5.1 如何判定特征有帮助？

使用实验 1 和实验 2 确定的同一训练方法、相同原始数据划分、相同更新预算与种子。比较原始四输入模型与“原始四输入＋一个特征”的验证指标，并特别看新增特征针对的区域：例如 q≈0 的静摩擦分界，或较长的撤力后时段。

如果总体改善很小，但边界区域明显改善，特征仍可能有价值；反过来，总体改善却让边界更差，也要如实记录。

6. 实验 3B：何时考虑分状态或混合模型？

如果简单物理特征后，错误仍集中在“始终静止”“移动后停止”“观察时仍在移动”的状态切换，可以考虑更复杂的结构。

一种方案是门控多专家模型：多个子网络各自预测，门控网络根据输入决定混合权重。最终预测可写为：

ŷ(x) = Σk=1…K pk(x) · fk(x)，  Σk pk(x)=1x 只能包含推理时可得到的输入；p 是门控权重，f 是各子模型的预测。

另一种方案是解析物理规则＋学习残差：先用已知物理公式给出基准预测，再让网络学习剩余误差。但如果标签本来就由完全相同的精确公式生成，直接使用公式可能已足够；这时“混合模型更好”并不能证明网络表示更强，应先明确研究目的。

最容易造成假提升的错误：用真实最终速度是否为零来决定选哪个子模型。这等于先看答案再预测。若要分状态，选择器必须仅依据 v0, F, t1, t 及其可计算特征工作。
