# E3: Longer learning-rate reduction patience

Compare the E1-A scheduler setting with E2 at 2,000, 4,000, 6,000, 8,000, and 10,000 optimizer updates. E3 changes only scheduler reduction patience from 200 to 500 updates. The initial learning rate (`0.001`), absolute improvement threshold (`0.001`), reduction factor (`0.5`), minimum learning rate (`0.00001`), model, data, and fixed 10,000-update budget stay the same.

The runner uses the same five seeds as E2 (`42`, `1006`, `10086`, `104792`, `230786`). Each E3 seed is one continuous run to 10,000 updates; the comparison uses checkpoints from the corresponding continuous E2 10,000-update run at the same updates. This isolates the scheduler change without comparing runs that have different stopping budgets. Check `evaluation_events.csv` to see when each schedule actually reduces the learning rate.

The extended E3 runner uses the same scheduler and seeds for separate continuous 20,000-update runs. Its 16,000 and 20,000 values are checkpoints from each 20,000-update run. It saves per-seed artifacts under `model_training/data/e3/runs/seed_<seed>_20000/` and five-seed means for every train and validation MSE scope in `model_training/data/e3/e3_extended_mse_means.csv`. The earlier 10,000-update runs remain separate.

From the repository root:

```powershell
.\.venv\Scripts\python.exe model_training\first_training_experiments_update\run_e3.py
.\.venv\Scripts\python.exe model_training\first_training_experiments_update\run_e3_extended.py
```

Use `--seed 42` to run one seed first. The runner skips completed E3 seed directories and writes `model_training/data/e3/e3_vs_e2.csv` for the completed seeds. Detailed run artifacts are in `model_training/data/e3/runs/seed_<seed>/`. It creates `model_training/data/e3/group.json` so the Qt viewer can list the group. The reserved test split is not evaluated.

The extended runner also accepts repeated `--seed` options and skips completed 20,000-update runs. Once all five seeds finish, it writes the MSE means CSV. The reserved test split is not evaluated.
